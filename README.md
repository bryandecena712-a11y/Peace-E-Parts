# PEACE E-parts

A Flutter mobile prototype for browsing PC parts and previewing a demo order.

## Run the app

```sh
flutter pub get
flutter run
```

## Demo flow

- Sign in with an email and password, or choose **Explore as a guest**.
- Browse eight PC-part categories with product photos and select product specifications.
- Save products to Likes, adjust the demo cart quantity, and review compatibility notes.
- Place a cash-on-delivery demo order and view it in Notifications or My orders.
- Prices are displayed in Philippine pesos, and the sample delivery location is Pansol, Calamba City, Laguna.

The catalog, sign-in, and checkout are demonstrations only. No account is created, payment is collected, or product is shipped.
